 # 🏨 HOSTEL MANAGEMENT SYSTEM

## 📌 Project Overview

The Hostel Management System is a simple Python-based console application developed to manage basic hostel activities efficiently. It helps maintain student information, record student entry and exit, manage complaints, register visitors, and provide important hostel information.

This project is designed to reduce manual work and make hostel management easier, faster, and more organized.

## 🚀 Features

The system provides the following 13 features:

1. **Student Entry:** Allows registered students to enter the hostel and records their entry time.
2. **Student Exit:** Records the exit time of registered students.
3. **Search Student:** Searches for a student using their registration number.
4. **View Records:** Displays all student entry and exit records.
5. **Emergency Help:** Provides emergency contact numbers.
6. **Hostel Information:** Displays basic hostel information.
7. **Complaint Registration:** Allows students to register their complaints.
8. **Mess Menu:** Displays the daily mess menu.
9. **Visitor Entry:** Records visitor details along with the student ID.
10. **Change Room:** Allows updating a student's room number.
11. **Student Count:** Displays the total number of registered students.
12. **All Students:** Displays the details of all registered students.
13. **Exit:** Safely exits the application.

## 📖 Working of the Project

When the program starts, it asks the user to enter the number of students to be registered. The student details are stored in a dictionary.

After registration, the main menu is displayed with 13 different options. The user can select an option to perform the required operation.

The system checks whether a student is registered before allowing entry, exit, complaint registration, visitor registration, or room changes.

The program uses the Python DateTime module to record entry and exit times.

All operations continue until the user selects the Exit option.
